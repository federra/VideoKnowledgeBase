# 榜单数据增量同步

2026-11-01。用于把本地新采集的榜单及评论同步到已部署服务器，用户要求不覆盖服务器已有数据。运行脚本为`scripts/append_collection_snapshot.py`；业务包、备份、差异与验收回执仅保存在忽略目录data/deploy，禁止提交Git。首次部署方法见[服务器部署](服务器部署.md)。

本地完成采集且所有任务终态、来源暂停后，导出一致性快照，SSH传至本项目私有目录并核对SHA，在独立cip_stage_*暂存库恢复。正式库绝不直接恢复dump。版本、组织、主键结构不匹配即停止；默认只比较，加--execute才导入。

只追加采集相关白名单表缺失主键，既有行全部保留；可变来源／作品／账号索引的差异记录后保留服务器值，历史证据差异及其他唯一键冲突直接失败。禁止更新会话、权限、模型配置、知识或选题；新增任务／连接／原包和依赖必须属于采集闭包。当前仅支持文件元数据及证据限制事件无新增／变化，发现此类差异即拒绝，不能遗漏后继续。

历史完成任务与已封存快照无法按在线新任务方式重放，因此仅在管理员单个导入事务内使用复制模式，导入后恢复origin并逐项校验全部外键、既有全组织业务约束、服务器旧行及新行SHA。只INSERT，不UPDATE／DELETE／TRUNCATE正式库；失败整事务回滚。正式执行前先在独立副本演练新增／幂等／冲突／回滚，正式库先备份并短暂停止本项目API／worker／Beat，finally恢复；不动其他应用，也不通过覆盖整库撤销增量。
