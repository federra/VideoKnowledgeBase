# 选题素材抽象与版本评分

更新：2026-10-31。依据：情报局模块十维genre-load-v3-inferred、九门K04题材承重方法；用户要求沿用控制台模型配置及不设系统自定义输出上限。实现／验收见[执行计划](../plans/2026-10-31-topic-quality/plan.md)与[验收记录](../plans/2026-10-31-topic-quality/verification.md)。

## 一、两阶段生成与相似性

新topic.generate/v2：冻结真实来源→第一次模型抽象→第二次模型创作→本地筛查→整批发布或拒绝。沿用topic控制台绑定，预算最多2次、1次attempt；不自动纠错／重试。旧v1任务与六张已有卡保持可读，不回写旧证据。两阶段调用分别保存AIExecution、精确请求清单／输入SHA、响应私有文件／SHA及用量；第二请求只含抽象机制和用户私有闪念／方向，不含原情报简介、来源ID或原作专名。

抽象逐条绑定冻结来源ID，提炼情绪／冲突／代价／结构；拒绝伪造、缺漏或重复来源，专名必须出现在对应原文。机制中禁止原句和专名；创作不得复用已识别专名，发布时重新读取两次私有响应核验任务归属、调用编号、文件SHA和结构。脑暴改稿保存及v2卡片人工编辑重新读取精确名称表，防生成后手工恢复原人名绕过检查。

quality.screen仅比较本批冻结外部来源，用户自己的闪念是创作意图，不作为抄写证据。归一化NFKC／大小写／字母数字；连续片段≥12字、共享6字元组≥6且占候选元组≥35%、复用来源作品标题（≥4字）提示风险。知识库题材／方法标题为可复用概念，不套作品标题规则，长原句规则仍适用。风险整批不发布；无外部来源的手工创作允许“尚未检查”，旧卡保留并展示风险。启发式阈值是工程筛查规则，不是版权结论，不能识别全网或所有语义换写、不能据此认证原创。

## 二、确切版本评分

新提交使用topic.score/v2，必须由控制台topic_score环节绑定；不借用topic配置。单次显式提交仅一次模型调用、一次attempt。当前量表genre-load-v3-inferred只适用国内80集AI漫剧，故事短片暂无适用量表；接口返回RUBRIC_UNAVAILABLE，不套80集规则，不新增立项分数线。

十维顺序固定：emotion／conflict／contrast／antagonist／twist、audience／platform／acquisition／sequel／differentiation。每项为0～5严格整数或null（不是0），保存文本依据；服务器求内容／市场各25及总50，任一缺项则对应合计null。按用户最新决定，市场五项由AI根据创作定位、文本与常识推断，不再因缺少独立市场证据强制null；每项保留推断理由及不确定性。推断不冒充实测用户规模、CPI、收益或平台验证，不编造统计数据；确实无法判断才保留null。

输入冻结选题确切修订、字段SHA、来源、量表和控制台模型精确版本；执行与发布实时核验。旧版评分不能用于新版，执行中编辑令旧任务失败而不污染新版本；失败／证据不足明确显示，不补假分。0031建立不可变topic_assessments；0032仅扩展量表CHECK与typed守卫，新量表绑定v2任务，旧genre-load-v2仍绑定v1且市场五项为null。守卫继续核验组织／选题修订／任务／AIExecution及配置绑定、维度顺序／整数／合计，禁止修改和删除评分事实；不增加表、列或应用权限。已有v3记录时拒绝降级。

## 三、界面、接口与运维

新市场评分组显示“AI推断”；market_basis由服务端按量表派生，旧量表unavailable、新量表ai_inference，模型不能自报为实测。历史评分不改写，LegacyScore仍执行v1旧规则。本次修订与真实验收见[实施记录](../plans/2026-10-31-market-inference/verification.md)。

POST /api/v1/topics/{id}/evaluate {expected_version} 返回202任务；GET /api/v1/topics/evaluations/{id}仅查询。使用现有身份／CSRF／幂等；原key和版本先存成员范围sessionStorage，响应未知仅显式同键恢复，不自动另发。卡片左上角及详情沿用Demo承重评估；空分为—，不画有效比例条。编辑立即隐藏旧分，保存并重新评分先提交新版本再执行。页面读取、配置保存、任务轮询均不发模型请求。

app/topics/execution.py：统一调用保留预算检查、checkpoint、失败用量及响应证据；生成worker时限1260/1290秒、评分660/690秒，覆盖合法配置每次最长600秒。仍独立topics队列，仅broker传opaque ID；输出上限null时省略max_tokens，由供应商默认／硬上限控制，DeepSeek使用非思考模式。后续接入其他供应商／评分量表或独立市场证据时须新增版本及相应验收，不改旧评分。

生成流程、完整系统提示词及旧11张卡来源区别见[选题卡生成逻辑与提示词](选题卡生成逻辑与提示词.md)。
