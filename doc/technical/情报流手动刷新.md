# 情报流手动刷新

日期：2026-10-22。用户确认：日期左侧增加“重新采集”，当前业务线所有现用渠道刷新；同步单文件Demo。沿用现有连接器、任务／调用／原包／不可变快照和审计，不新增表或权限，不启用定时采集。

## 一、入口与接口

正式React和[单文件Demo](../prototypes/index.html)均在情报流日期左侧放置按钮。正式按钮发起`POST /api/v1/intelligence/refresh`，仅接受`business_code`，需既有会话、Origin、CSRF和UUID幂等键；`GET`同一路径以`business_code`读取最近批次，刷新页面、查进度及切日期不会采集。运行／设计OpenAPI及前端类型均同步。

批次日期由服务端确定为上海当天，点击后切换顶部日期。与当前视频／小说、平台、题材、历史日期筛选无关。当前权限须具备source.configure、collection.run、content.read、evidence.read、task.read；本地工作区沿用现有授权，不自动扩权。无既有配置的渠道明确显示不可自动采集，不擅自把其他业务的来源复制过来。历史红狐关键词／榜单不参与；新增显式配置的博主主页按[博主手动采集](博主主页配置与手动采集.md)作为可选第五渠道。

本轮仅支持`LOCAL_SINGLE_USER=true`的既有本地模式。批次由API进程内显式后台线程运行，复用有租约／心跳／权限重验的Runner；普通Celery的50／60秒限制不足以完成低频多渠道采集，关闭本地模式时POST明确503。刷新父任务、小说／红果／TikHub采集和系列归一化均与通用sweep／worker隔离。未来服务器部署需要另行接入长任务专用执行器，不能直接启用通用队列代跑。

## 三、批次、替换展示与恢复

父任务kind=`intelligence.refresh`、version=1、max_attempts=1、max_external_calls=0；该零预算仅指父任务本身不请求来源，实际外调由每个有独立一次预算的子任务计数。来源／连接／请求清单保存为manual原包及SHA并封存输入，使用既有http_receipts、tasks、task_inputs、audit_events和task_outputs，不增加新表。每次成功提交后新的点击创建新批次；相同幂等键始终复用原回执，同组织同时只容许一个活动批次，另一业务线请求返回版本冲突。

子任务幂等键为`refresh/<批次UUID>/<渠道>/<能力>/<请求SHA>`；各子任务临时启用其来源，finally暂停，旧CLI的同日一次保护保留。各来源形成当天新版本，不删除、改写或撤回旧快照。渠道未全部成功时，新榜单与新评论样本不进入情报流最新展示；发布审计`intelligence.refresh.published`与渠道绑定后才可见。起点的部分更新只发布男频，女频旧快照保留。历史证据、报告及直接ID引用保持原版本。

进度按渠道追加审计；页面每3秒只读查询，完成后失效已有情报查询缓存。读取短暂失败时保留已有活动任务、禁止再次提交并继续核验；鉴权变化按已有ApiProvider边界取消缓存／请求。跨上海日期停止，不把次日原包写成昨日。进程中断后不会自动重发外部请求；读取状态可将过期父任务租约标为失败，已成功发布渠道保留，未发布渠道旧展示保留。若进程被强制退出，需检查中断子任务及临时来源状态；不将普通刷新当作不确定付费调用的自动重试。

Demo仅演示按钮位置、等待／完成反馈与防重复点击，明确标注“交互演示，不请求真实渠道或覆盖真实数据”，不伪造采集成功。

## 2026-10-23 显式同日续采

原父任务failed但部分渠道／子任务已成功时，不能再次点击全量刷新来恢复。使用`refresh_resume.py`与`scripts/resume_intelligence.py --batch <UUID>`建立独立关联续采父任务，原failed及冻结输入保持；同日、当前权限、来源与并发均校验。成功渠道跳过，未发布渠道复用原batch子键及成功原包，番茄已完成目录／字体校验复用原审计；失败或未知请求不自动重发。历史未发布博主尝试只在入场检查，运行中心跳不以自身新建子任务为失效理由。普通worker／sweep排除resume种类；最新进度读取覆盖关联续采，发布需同事务重检权限／日期。独立进程不依赖页面或API进程内线程寿命，仍需电脑和本地数据库保持运行。实际原因及完成情况见[本轮续采记录](../plans/2026-10-23-情报榜单中断续采.md)。

任务心跳对PostgreSQL `55P03`（锁等待超时）返回“尚未完成检查”，不能当作授权成功或撤权。后台等待下一次检查；前台最多等待10秒，必须重新成功验证有效租约、当前权限及冻结输入后才继续，超过期限返回`LOCAL_TRANSIENT`。明确租约／权限失效仍停止，其他数据库异常不忽略。刷新／续采父任务租约为180秒；发布与任务完成的有效租约检查保留，不清理来源冷却或重发外部请求。
