## 一、依据与读图方式

本文从[当前 Demo](prototypes/index.html)的页面渲染、动作分发及表单提交逻辑还原交互，记录用户从哪里进入、做什么、结果存在哪里、如何返回，以及流程在哪一步停止。2026-10-15用户已指定Demo为前端强制开发基准，开发必须严格复现其页面与交互；本文及配套图作为操作索引，文字或图滞后时以当前经用户确认的Demo为准。[PRD](AI知识库产品需求文档_PRD.md)与[四模块交互架构](四模块交互架构.md)继续约束业务范围及交接，不因Demo尚未接入某项能力而取消需求。视觉细节见[DESIGN](DESIGN.md)。

图分为8页，节点编号与下文一致。蓝色为页面，紫色为详情／只读区，橙色为表单／人工操作，黄色为条件或校验，绿色为本地结果，灰色虚框为未接入能力或流程停止点。带“↗”节点可在 draw.io 中跳转到关联图页；这些是图册阅读链接，不是新增的产品按钮。实线表示用户操作或本地数据变化，虚线到灰框表示能力边界，不表示后台正在执行。

本地输入、预置结果与真实服务分开：来源、封面、评论、评分、阶段报告和表现数据可含固定演示样例；新增输入保存于当前浏览器，未调用采集、解析、模型、任务调度或外部生产系统。`?qa=1`仅为隔离验证入口，不属于用户正常操作流程。

## 二、公共导航与跨模块交接

一级入口按“情报局 → 研判室 → 藏经阁 → 控制台”排列；各模块的二级 Tab 独立切换。业务线初次默认故事短片，此后读取本地选择；业务范围跨模块保留，主题也本地保存。常规切换模块／Tab重置局部筛选，切换业务退出当前作品；作品页的“返回作品列表”保留该列表筛选。作品面包屑“研判室 › 内容研判 › 作品名”前两级均可返回内容研判入口。

| 模块 | 二级工作区与路由 |
| --- | --- |
| 情报局 | 情报流 `#0/0`；选题卡 `#0/1`；待生产 `#0/2` |
| 研判室 | 内容研判 `#2/0`；发布复盘 `#2/1`；规律验证 `#2/2` |
| 藏经阁 | 知识浏览 `#1/0`；入库处理 `#1/1`；审核队列 `#1/2`；回收站 `#1/3` |
| 控制台 | 采集配置 `#3/0`；处理配置 `#3/1`；评价标准 `#3/2`；权限管理 `#3/3`；运行状态 `#3/4`；模型配置 `#3/5` |

跨模块有三类实际交接：情报人工初评写入研判记录；研判候选写入知识审核对象；控制台名单／榜单配置改变情报筛选选项。选题交接通过复制或导出给外部系统，未建立生产系统接口。规律验证与控制台标准页的往返仅为查看入口，不构成验证后自动发布标准。

普通详情关闭回到原页；编辑表单未保存离开时确认放弃，取消则留在表单。校验错误显示在当前表单并保留输入，不跳成功页。列表无数据／无匹配展示空态，不填入其他业务数据；未知值不作为0或成功。当前还保留状态预览逻辑，但原型说明入口已隐藏，不将其列入主要用户流程。

## 三、情报发现、选题与交接

### 1、情报流与人工研判

主路径：`I01 → I02 → I04 → I05 → I06／I07 → I08 → I10 → I11`。提交成功后留在情报流；用户之后自行切换研判室，不强制跳页。

情报来源切换为视频／博主／小说，前两者承接原榜单／达人。条目中小说只展示在读人数，不显示视频互动统计与洞察；顶部三类来源都使用视频／博主／小说三项数量概览，不受局部筛选影响；本地固定样例仅属最新演示日，真实小说接口未接时React显示空态。日期改变时视频指标、榜单、博主和洞察使用同日快照；无快照明确为空，不回退最新。标题或简介溢出时悬停／聚焦查看全文，离开或Esc关闭。观众反馈抽屉可定位样例证据，也可进一步送研判。

作品名匹配是当前本地资料中的预填／匹配演示，不是已接入模型的真实归属判断。漫剧同名作品必须明确选择具体对象；当前集号可未知，不能根据相似标题强行编号。提交时保留来源日期、互动与反馈快照、人工评级及学习点，后续补充不抹去原初评。

### 2、选题编辑、评分与待生产

主路径：`T02／T03 → T01 → T04 → T11 → T12 → T13`；人工编辑重评分支为 `T05 → T07 → T09 → T10`。选题确认不依赖先做研判。

卡片／标题／评分／编辑打开同一抽屉。角色设定只有一个自由文本框。漫剧承重力内容5维、市场5维，各5分；卡片显示当前版本总分，详情显示十维及条形。人工新建没有评分时不填样例分。实际改动后“保存并重新评分”启用，改回原值恢复禁用；保存后旧内容和评分留历史，新版本待评分，Demo没有生成重评分结果。

“加入待生产”可独立点击；需要主业务线，电商选题流程当前暂缓。复制成功或导出才记录交接；剪贴板失败打开手动复制框，需人工确认后记录。标记已采用只表示人工选择，不表示外部制作完成。

## 四、作品研究与知识沉淀

### 1、作品、分集、报告和资料

主路径：`W01 → W03 → W04／W05／W06`。AI漫剧默认分集分析；短片等使用“内容分析”文案，不强制编号第1集。作品列表状态筛选可交叉命中，数量不能相加；已有报告与处理中／失败任务并存。

作品页路由以 `#2/0/work/<作品ID>` 为前缀：`/episodes/<单元键>/<任务ID>` 定位分集及材料版本，`/analysis[/<报告ID>]` 定位作品报告，`/materials` 查看资料记录。报告证据进入对应单集、任务并定位片段；浏览器路由可恢复选择与分段。

分集导航每集一行，集号＋标题，有资料与缺资料使用不同字色，不设搜索框或状态下拉。已知总集数列全量，未知则依据明确集号列至当前最大集号；未标集另列，不按标题或旧汇总数量补造材料。超过100集分段。同集多版本归组，当前失败不掩盖旧成功记录，也不将旧成功算作新版本成功。

作品概况为总集数、已收集、已分析、最新报告、总观看量、互动量；表现缺失可空白，真实0保留。历史汇总不冒充可逐集打开的记录；累计表现快照不相加，互动分项未齐时不强行求和。

作品分析用一个连续文章展示0—9：优缺点、故事大纲、情绪与母题、人物设计、世界观与长线悬念、情节与冲突、节奏结构、终局设计、剧情发展高潮曲线、观众评论反馈总结，每部分包含事实分析与改写建议。无报告保留待分析框架；高潮曲线只使用本报告范围已有点，人工初评单独留档。报告版本保留自身覆盖范围，新补材料不改变旧报告。

补资料区分作品级与单集级：作品级只增加资料，单集级新增待处理记录，同集形成新版本、不重复计集数。失败重试只限当前失败记录，创建新执行并保留原初评和历史结果。现有80集样例可同时展示40集已分析、10集分析中、5集解析失败和覆盖10／25／40集的阶段报告；这是预置阅读样例，不是提交后自动算出的结果。

“至少一集有效分析、批次结束或阻塞后生成阶段报告”等业务讨论仍见[研判室模块文档](modules/研判室.md)，当前Demo没有实际执行该生成状态机，因此图在W12停止，不绘制自动成功回路。

## 五、闪念与头脑风暴

`B01 独立闪念 → B02 组合区 → B03 生成并编辑 → B04 保存为选题卡 → T04 统一详情`。闪念弹窗左记右看，自动保存并可随时打开历史胶囊；不直接生成选题。选题卡“新增选题”右侧打开头脑风暴，拖入或点击历史胶囊，支持多条去重与移除，可补充方向。生成与保存是两个步骤，空组合不可生成；修改输入使旧结果失效。方向／组合／结果按业务保存在本地，存储失败明确提示并保留输入。
