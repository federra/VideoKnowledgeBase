## 一、参考项目与采用方法

用户提供入口：[红果热播榜](https://hongguoduanju.com/rank/hot-drama)。参考[Douyin_TikTok_Download_API](https://github.com/Evil0ctal/Douyin_TikTok_Download_API)和[MediaCrawler](https://github.com/NanmiCoder/MediaCrawler)的“平台独立连接器→请求／解析→统一数据结构”方法。本轮核对两项目main公开平台目录：前者为douyin、tiktok，后者为bilibili、douyin、kuaishou、tieba、weibo、xhs、zhihu，均未列红果独立平台适配。不能把抖音接口、aweme_id或签名直接套到红果域名，也不能声称已经使用两项目现成红果接口。[目录核验](verification/2026-10-20/hongguo-reference-directories.json)。

本页普通请求已能取得服务端渲染的完整榜单正文，因此当前最小方法是原生HTTPS＋HTML解析，不需要引入整个爬虫项目或浏览器签名／身份池。本轮没有安装、运行、复制参考项目代码；MediaCrawler适用授权规则沿用[技术研发方案](技术研发方案.md)，不影响本轮独立实现的公开HTML小样研究。若后续HTTP来源受限，应单独验收站方允许的访问通道，不能仅凭本次成功承诺永久无需登录。

## 二、真实读取与字段口径

探针仅对指定URL执行1次普通GET：HTTP 200，341177字节，UTF-8 HTML；不传Cookie、Authorization，不关闭TLS验证，不跟随重定向，响应上限4MiB。原始HTML保存在Git忽略的data/hongguo目录；响应SHA256为7384d7689ee3d131209a6c67c4b3dc31d08bc7999e5e2c36cd163ca557b8a00a，采集时刻2026-10-20T15:15:26.086528+00:00。另以正常浏览器查看同页、只读核对参考项目，浏览器资源加载请求未逐一统计；此处“1次”仅指HTTP采集探针，非本轮所有网络请求。

页面原文“10月20日已更新 · 基于红果内观看/互动等综合热度排序”。只有月／日展示，保留原文并另外记录完整抓取时间，不伪造榜单发布时刻。首屏20条，名次连续1～20且书籍／短剧ID无重复；标题ID与详情链接series_id交叉校验。第一条《觉醒伪神：神明弃我我自为神7》，热度8070万热度、评分评分9.1、收藏68.5万收藏、点赞221.2万点赞，其简介162字。浏览器后续读取时赞藏显示有变化，因此不同请求的值不混写成同一快照。

| 字段 | 可提取来源／口径 |
| --- | --- |
| 原名次、作品ID、标题、详情链接 | 卡片序号、h2[id^=rank-title-]、同卡/detail?series_id=；维持页面顺序 |
| 完整简介、题材标签 | 卡片description段落、categories里的span；不从剧名或简介猜标签 |
| 热度、评分 | 明确带“热度”“评分”的页面文本；热度是综合指标，不能映射view_count |
| 点赞、收藏 | 明确带“点赞”“收藏”的页面文本；保留raw及单位换算展示值，标website_display_rounded，不能当精确原始计数 |
| 播放量、评论、分享 | 当前榜单页未取得，保持null，不取其他指标替代 |
| 总集数、视频文件 | 未取得；展示的选集入口不是已验证总集数，player链接也不是视频文件地址 |

“8070万”可换算展示值80700000，“68.5万收藏”可换算685000，使用项目已验证的Decimal人数单位解析工具；这只是单位换算，不能恢复被页面舍入的精确值。本站热度、评分及数值显示精度需要在正式接入时作为独立指标／来源元数据设计，不能把综合热度塞入现有播放量列。

## 三、可复现方法与接入边界

以ol[aria-label=红果热播榜]限定榜单区，每个article为一个作品；用h1、canonical URL限定正确榜型与第一页，用h2的rank-title-ID及/detail?series_id双重识别；pc-badge-number-类前缀读名次，pc-metrics-读热度，ul[aria-label=作品互动数据]逐项识别评分／点赞／收藏，pc-categories-下span读题材，pc-description-读完整简介。CSS只匹配稳定前缀，不依赖构建哈希后缀；结构或字段意义变化时拒绝解析，不返回假空榜。未执行页面脚本，也未把SSR请求元数据写入公开证据。

离线探针：[源码](verification/2026-10-20/hongguo-rank-offline-probe.py)。在项目根目录运行 `backend/.venv/bin/python doc/technical/verification/2026-10-20/hongguo-rank-offline-probe.py`，只解析已保存HTML，外部请求0、业务库写入0。完整简介只保留于忽略目录data/hongguo/parsed-first-page.json，公开证据仅放字段、指标、简介长度及断言，不发布批量简介原文。[20条提取及5项校验](verification/2026-10-20/hongguo-rank-probe.json)全部通过，探针Ruff检查通过。

正常浏览器首次可访问性树已展示20个作品及其热度／简介／互动数据，前三名与HTTP样本一致；随后自动化DOM批量读取超时，未得到可持久化DOM对照／截图，不将其记为完整DOM交叉验收。这一工具读取限制不影响已成功的普通HTTP正文解析，也不能归因源站403或风控。未为此重复采集或调用付费服务。

正式接入的建议：新增独立hongguo平台／热播榜来源，先只采第一页前10条，经既有任务预算、权限、原包留证、不可变观测／快照及幂等链路发布；点赞与收藏需明确展示精度，保留热度／评分独立含义。前端沿用现有榜单选择，不与TikHub混成同一来源；平台字典及必要契约／迁移须另行设计验收。本轮未改业务代码、数据字典或页面，未跑全套产品测试，未启用后台采集。

同页导航还列真人剧、AI剧、漫剧热播榜：/rank/hot-real-drama、/rank/hot-ai-drama、/rank/hot-comic-drama；本轮只验证用户指定/hot-drama，不能把总热播榜当AI漫剧专榜，其他榜型及分页尚未实测。
