# 服务器部署与数据迁移

2026-10-31。用户明确授权部署且不设置登录密码；服务器连接资料位于本地.env的DEPLOY_HOST／PORT／USER／PASSWORD，不记录真实凭据。Git提交仅源码、配置模板与技术文档，业务数据库／评论原文／导出／运行文件和新增数据验收附件不入Git。部署计划见[本次清单](../plans/2026-10-31-server-deploy/plan.md)。

## 一、运行结构

独立目录`/opt/video-knowledge-base`：`releases/<Git SHA>`保存不可变代码，`current`指向当前版本，`venv`为Python3.12运行环境，`shared/.env`保存应用运行配置（排除DEPLOY_*），`shared/data/files`保存私有关联文件，`shared/redis`为独立Redis数据。运行账户`cip-vkb`不交互登录，私有文件目录700、配置600。

本次服务器已存在其他项目，复用其Nginx HTTPS证书和443站点，仅增加`/vkb/`子路径；API监听127.0.0.1:18090，独立Redis监听127.0.0.1:16379，新建独立业务数据库，不改旧库。已有IP证书由原certbot.timer自动续期；不得替换其他站点、全局数据库凭据或关停其服务。目标地址和最终SHA以私有部署回执为准。

前端用`pnpm --dir frontend exec vite build --base=/vkb/`，BASE_URL固化为/vkb/；统一API传输加同源前缀，Hash导航及相对assets保持。Nginx把/vkb/api/转至后端/api/，并将会话Cookie Path由/api/v1改成/vkb/api/v1，浏览器不会将其发往其他站点路径。配置模板在[infra/server](../../infra/server/)。

## 二、免密码共享工作区

服务器配置`LOCAL_SINGLE_USER=false`、`PASSWORDLESS_ACCESS=true`、`SECURE_COOKIES=true`，ALLOWED_ORIGINS仅填写实际HTTPS源（scheme＋Host＋端口，不含/vkb/路径）。这是显式共享模式：知道网址即可进入同一个既有工作区并使用其已有权限，不设登录密码。默认PASSWORDLESS_ACCESS=false，本地loopback规则保持。

入口仍检查原始Host、可信ASGI scheme、精确Origin、跨站请求；会话只GET，保留HttpOnly／Strict SameSite／CSRF与业务来源鉴权。Nginx覆盖Host与X-Forwarded-Proto，API仅loopback，Uvicorn仅信任127.0.0.1代理。不要用伪造localhost Host来绕过本地门禁，也不要把数据库、Redis或私有文件目录直接暴露给浏览器。

## 三、数据、发布与回滚

本地PostgreSQL用一致性自定义格式dump（不携带角色凭据和ACL）单独SSH上传。服务器在独立新库恢复，安装pgcrypto／vector扩展、按现有grant_application规则创建受限应用角色；运行连接不能拥有表、SUPERUSER、CREATEDB、CREATEROLE或BYPASSRLS。迁移管理通过SSH下的数据库管理员执行，运行应用不持管理员口令。

另传本地data/files私有对象快照；迁移保留榜单、评论、知识／附加解释、选题／评分、模型控制台分配、原包与结果引用、暂停状态。对核心表计数／版本与全部文件SHA256逐项比对。独立浏览器Profile、Cookie、运行日志不复制；抖音等独立浏览器采集会话须在服务器单独准备，不能宣称本地会话已移植。模型密钥引用保留，实际值仅在应用.env，验证不额外付费调用。

以systemd启动API、worker及Beat，源暂停和任务终态保持；部署本身不重采、不重跑评论批次。外部HTTPS验证空Cookie进入、业务列表／知识／选题、原文文件及无密码模式，不以健康接口替代业务验证。细节回执保存在忽略目录`data/deploy/`，不提交业务快照。

新版本切换current前保留旧release、原Nginx配置备份和新库恢复前记录；只替换本项目服务。首次部署新库不会覆盖原服务器其他数据库。未来数据库升级需先快照和兼容验证；0035已有批次数据时拒绝直接回退，不能以切代码代替数据回滚。
