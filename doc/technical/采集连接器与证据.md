# 采集连接器与证据

版本：v0.3｜日期：2026-10-17｜阶段：S06.1。范围：AI漫剧／抖音／红狐账号发现和广域库账号作品元数据；来源计划及控制台在S06.2，真实情报页在S06.3。数据结构服从[首批字段字典](数据字典-首批字段.md)B1-b，任务状态服从[任务基础](任务队列与调度.md)。本轮不新增表／列或迁移。

## 一、能力与预算

固定能力`douyin.account.search`（[红狐账号搜索](https://redfox.hk/apis/douyin/P5CHB3BZ)）对应关键词来源，固定offset=0、sortType=_0；`douyin.creator.works`（[红狐广域库作品](https://redfox.hk/apis/douyin/QSL2ZSXM)）对应账号UID，固定pageNum=1。处理器版本redfox-v1，唯一主机https://redfox.hk，路径写在适配器内，不能由请求传入URL。供应商分页、质量库降级、换供应商、评论和媒体抓取均不会自动发生，未支持能力明确拒绝。

本阶段每任务max_requests=1、max_items=1～3、max_attempts=1；作品pageSize对应max_items；账号搜索接口未提供本地条数参数，可能返回20条，但只形成最多3条观测与快照条目，返回条数仍据实记录。每组织／连接最小间隔2秒；429记录响应并失败，不按Retry-After自动再次付费。5秒网络阶段超时，20秒总超时，1MiB响应上限，拒绝压缩响应及重定向，关闭环境代理。网络结果不明保留EXTERNAL_RESULT_UNKNOWN，已有任何外部预留均不自动重试；进程中断后的恢复沿用0007保守规则，不能把已付费请求当未执行。

连接仅保存secret_ref=REDFOX_API_KEY，密钥从私有.env读取，不写入任务、数据库安全参数、回执或队列。响应证据会替换其中回显的实际密钥，记录的是替换后正文的SHA；超大、非UTF8、部分响应有显式包装，不冒充完整原文。无供应商账单证据时，provider_reports_charged及费用均NULL，不能把未知费用记为0。

## 二、身份、缺失与历史

平台UID、作品ID始终为字符串；同名不合并。账号总获赞与作品点赞分字段，0与缺失NULL区别保留，时长按毫秒，不凭空填播放量、榜单名次、评论或完整剧情。缺失图片列表／标签落SQL NULL，而非JSON null或空数组；显式空数组仍保存[]。无时区发布时间保留原始字符串，绝对时间和时区NULL。

安全原始链接只保留抖音／iesdouyin HTTPS域，图片限已知平台CDN；不访问或声明外链仍可用。无效／非白名单链接置NULL，响应原文仍可追溯。必需ID、计数格式、响应结构错误或返回作品作者不匹配会失败；成功空list才生成entry_count=0快照，错误不能伪装为空列表。同页相同ID完全一致时去重，冲突时拒绝整页；跨Call不合并观测，平台身份复用，版本独立。

显式更换同一供应商连接可共享平台身份，但Job、Call、RawAsset、Observation、快照版本及连接引用各自保存；新供应商需单独实现和验证。本轮“换源”只验证两个明确红狐连接，不声称已支持其他供应商。

## 三、事务与权限

提交：当前会话／CSRF→Source可见性与collection.run→预算／幂等→连接和能力→同事务Job、输入封存Task、审计与回执。客户端不能传org/member/执行人、供应商URL或密钥；相同键相同请求返回原Job及Task当前状态，异参409。重新提交新键属于新的费用意图，不自动产生。

执行：重检来源、连接版本及当前授权→领取任务租约→同事务预留唯一Call及额度→提交预留→一次外部请求→独立事务保存已发生的Call结果与RawAsset→再次检查当前授权／租约→同事务创建身份观测、封存快照、Task输出和成功状态。数据库组织锁不跨网络持有。撤权或租约失效后仍保留已发生的请求证据，禁止正式发布；只发布采集业务日与证据Asia/Shanghai日期一致的快照，跨日返回DATE_WINDOW_MISMATCH，不把旧任务响应算成今日数据。

## 四、本地使用与验收边界

需先配置.env、迁移0007_tasks、受限应用登录和有相应Grant的成员，不创建默认账号。`pnpm collection --help`列受控命令，密码交互输入。`connection-add --org <UUID> --login <账号> --name <连接名>`创建固定红狐连接；`source-add --org <UUID> --login <账号> --name <来源名> --kind keyword --value 漫剧 --enabled`建立关键词来源，账号作品则kind=account、value为稳定UID。来源默认不启用，需显式--enabled。配置动作检查source.configure，不等于运行授权。

启动采集需`pnpm collection start --org <UUID> --login <账号> --source <UUID> --connection <UUID> --capability <能力> --key <新的UUID> --allow-paid`，默认只处理1条。命令提交后由`pnpm worker`和`pnpm beat`执行；`pnpm tasks status`读取受权任务状态。**本轮没有执行上述收费启动命令**，不要为复核重复运行历史probe。HTTP `POST /api/v1/collection-jobs`同样需要会话、Origin、CSRF、幂等键与权限；提交即明确授权请求中限额内的一次调用，返回202仅说明已受理。

本轮复用历史真实响应离线核验映射，不导入项目库、不伪装为新Call／当日快照；新增连接器的外部实跑尚未进行。PG测试供应商传输为合成响应，验证事务和失败路径；既有Redis／Celery为真实本地进程回归，两者不等于红狐持续在线证明。证据与审阅见[执行记录](../plans/2026-10-17-S06.1采集连接器与证据.md)。
