## 一、唯一维护源与实现状态

运行接口唯一机器契约是FastAPI `/openapi.json`，离线快照为[runtime.openapi.json](openapi/runtime.openapi.json)。截至2026-10-20，运行55项操作（health＋54项业务），首条链路设计[first-chain.openapi.json](openapi/first-chain.openapi.json)共59项（health＋58项业务），其中54项业务已实现、4项仍设计态；逐项状态见[生成清单](openapi/接口清单.generated.md)。设计app不挂入运行app；planned预览合法形状返回503，不调用数据库／模型。

S07.4接入13项操作：知识正式列表／详情、候选创建／队列／确切修订读取／新增修订、审核请求／详情／人工决定、正式发布、原子人工通过并入库、报告候选提炼。正式列表本阶段只实现分类／关键词和实时权限隔离，mode=semantic明确503，S07.5另验。候选／发布／审核均有真实HTTP与隔离PG事务验证；实际付费模型效果按用户决定后验。响应仅投影契约字段，不暴露内部org、actor、配置／文件密钥。

## 二、共用传输、会话和权限

普通请求／响应为UTF-8 JSON，字段snake_case；文件上传／下载是application/octet-stream原始字节，上传元数据在query，文件GET成功响应不包JSON信封，错误仍为统一信封。内部ID是UUID；抖音等外部ID始终字符串，不解析成number。`bigint`计数、lock_version、authz_version、report_generation和秒偏移用十进制字符串（不超过9223372036854775807），版本正数、计数非负，拒绝前导零、负数及JSON number；numeric(20,6)用最多14整数位／6小数位的十进制字符串，不用浮点重算摘要。普通页码、位置、单集号和样本条数用安全范围integer。未知指标必须NULL，真实0为`"0"`；空列表与未知NULL不同。

系统绝对时间输出UTC ISO8601，6位微秒及Z；仅接受带时区绝对时间。业务日为`YYYY-MM-DD`，按Asia/Shanghai解释，不拿供应商无时区的publishTime填绝对时间。来源原时间保留raw字段；摘要和固定输入由服务端按字典v1生成，客户端不提交input_sha256、normalization_version、actor、org或冻结时间来决定事实。

成功业务响应：`{"request_id":"UUID","data":...}`；分页内容在data内。错误响应：`{"request_id":"UUID","error":{"code":"稳定代码","message":"安全说明","field_paths":[]}}`，X-Request-ID与正文一致；不回显密码、密钥、完整正文、输入值、原供应商响应或任意额外字段名。普通JSON请求未知字段拒绝，不静默吞入模型参数。私密响应和错误使用`Cache-Control: no-store`；健康检查仍按原契约。

会话方案已由[S05.2公共服务](登录权限与审计.md)落实：服务端不透明会话，cookie名cip_session，HttpOnly、SameSite=Lax，生产Secure；开发仅明确localhost场景允许HTTP。登录使用本地开户给出的org_id＋login_name＋password；无自注册，错误统一AUTH_INVALID，不泄露账号是否存在。GET session返回当前成员、安全动作提示、authz_version、CSRF令牌和到期时间；动作提示只控制UI，不替代服务端检查。登录须校验Origin／同源并限流，其他写请求必须带X-CSRF-Token；写请求验会话后再验CSRF和当前权限。logout成功撤销当前会话，重复退出允许成功；缺失／过期会话读写返回401。

除登录的组织选择外，业务请求不接受org_id、member_id、执行人或审核人；组织与动作身份只取服务端会话。检查顺序：会话／CSRF→对象可见性与完整依赖→操作动作→幂等重放→版本及业务条件→同事务落库／审计。对象不可见与不存在统一404 NOT_FOUND；可见对象缺少本次操作动作返回403 ACCESS_DENIED。列表、搜索、数量、分页、历史和输出引用先按当前权限过滤；旧缓存、已签cursor和任务ID都不授予权限。

接口清单中的基础动作取交集，条件动作另检：情报交接同时检查原Source和目标Work／业务及文件／证据依赖；跨业务必须cross_business_confirmed=true且两边都有权。Task安全状态不附输入正文、worker_token、供应商请求参数或原始模型输出，outputs仅返回仍可读的目标引用。执行权限由服务端处理器固定映射：采集collection.run、解析content.write、分析／质量评价research.run、知识AI审核knowledge.review.run、报告AI审核report.review.run、预测prediction.edit、正式向量生成knowledge.publish。管理员无隐式放行权。

## 三、首条链路请求与业务响应

1. 来源和采集：SourceTarget按kind严格区分keyword/account/content/board，不混用槽。创建默认enabled=false；只允许PATCH展示名和启停，business／platform／目标不可换义。采集请求明确source、provider_connection和已核验capability；服务端重检启用状态、平台／目标匹配及当前执行权限。默认max_requests=1、max_items=1，HTTP上限100只为输入保护，实际还受当前授权、Source／Plan和供应商能力限制，不能据此自动扩大预算。若来源一次不可控返回20条，max_items只限制后续处理量，Call必须保存实际返回数，不能声称只请求或接收1条。请求后202只表示Job／Task接受，不表示来源成功；HTTP200＋供应商失败码仍记失败，不生成成功空快照。未提供自动翻页／未知结果重发接口。

2. 情报读取：先GET snapshots显式选择business_code、business_date，可加source_id／view_kind；结果只含该日实际快照，无记录返回空列表，不回退最新日期。GET entries固定snapshot_id，page从1开始、page_size默认及最多10，支持q和account_id筛选；total是授权过滤后的精确字符串计数，页范围外返回空items。排序固定position、id，真实provider_rank可NULL。账号发现和作品观测用kind区分，账号follower_count不是视频view_count。反馈仅凭明确feedback_id读取，历史快照无反馈就NULL，不借当天结果。跨上海日live结果返回DATE_WINDOW_MISMATCH，不改Job原日冒充历史指标。

3. 研判交接：POST research/submissions精确引用snapshot_entry_id及可空feedback_id，target按kind选择现有work_id＋expected_lock_version，或明确新Work名称／业务；同名不能自动合并。grade为S/A/B/C，题材非空，并至少一项学习标签或非空学习说明；漫剧单集／总集数可空，非空必须正数且单集不超过已知总数，非漫剧禁用集数字段。服务端还核对现有Work业务及集数、原快照反馈归属、实际材料与来源依赖。缺剧情／媒体不凭描述伪造完整素材；材料类型不符返回INSUFFICIENT_MATERIAL，reference可保留真实来源限制。202返回Submission资源ID和安全TaskRef，提交成功后留在情报流；不默示授权执行AI。

4. 输入及任务：ArtifactVersion至少正文／实际accepted文件／来源引用之一，版本更新用Artifact的预期lock_version；InputSet精确列材料版本、primary/reference及唯一位置，至少一个primary，同Work／范围由数据库与服务检查。版本、来源和证据清单封存后不改。Analysis请求只传input_set_id、execute_now和预算，不接受客户端处理器、actor或任意模型参数；服务端固定并冻结标准／配置版本。execute_now=false仅接受排队，true另查research.run及明确预算；缺配置或批准标准不假成功。后续GET Task安全状态；授权、取消和重试均带expected_lock_version与理由，授权预算不等于task.manage可代加额。running取消仅进cancel_requested；取消及过期租约先行，迟到结果不发布。未知外部效果禁止自动重试。报告／评价绑定输入和执行版本，缺证据不是0分或C，首批仅partial；AI正文子schema由S07按schema_version细化后才能启用真实报告接口。

5. 知识及复核：正式GET knowledge及详情只读published_publication指向的版本；修订生成新Revision，旧正式版继续可读，候选另走candidate.read路径。Demo“适用环节”映射到严格tags数组：kind=stage，code分别topic/script/asset/finished_video；读、修订和列表均返回版本tags，genre/task/platform标签同结构，不藏入正文。POST reviews由purpose确定具体表和动作，target_id只作HTTP判别输入，持久化必须写明确FK。knowledge_release普通送审需knowledge.edit，execute_ai=true需knowledge.review.run及预算；report_review需report.review.run；evaluation_review和standard_approval是人工路径，不增加强制AI调用。人工决定只接受verdict／reason／expected_head及所见AI，不接受AI结果或actor；Head ID与版本须同时空或同时有值。知识／报告人工approved需匹配当前AI approved；独立评价和初始标准不强加第二次AI。发布必须明确当前revision、review_request和两条决定，重新校验双审、摘要、当前Head及预期Knowledge锁版本后原子发布。修订／旧AI结果不能复用旧人工决定。既有estimable预测草稿冻结只接expected_lock_version，区间、条件、指标及时间从受限草稿和数据库复制；首次提交后确认，再返回201。缺确认重放只补确认，不重建冻结；撤销和草稿创建在S07完整细化，不能把预留GET当已实现预测资格判断。

## 四、分页、冲突、幂等和错误

除固定快照的10条页码分页外，动态Source／Work／Knowledge使用不透明cursor，limit默认20、最大100。固定排序created_at DESC、id DESC；cursor绑定组织／成员、当前授权世代、业务、过滤、排序及读取上界，服务端签名且有有效期。跨业务、换过滤或撤权后旧cursor拒绝CURSOR_EXPIRED，调用方清空游标重新读第一页；不能解码客户端游标作为权限。total可为NULL表示不提供精确总数，不能把NULL显示0；知识正式计数／分类计数在对应页面接入时另补精确统计契约。业务、q、分类、标签同时生效；tag参数使用kind:code（如stage:script），匹配正式发布Revision的tags内同kind同code，不使用候选标签；清页内筛选不清业务。语义检索无可用模型返回MODEL_NOT_CONFIGURED，不拿关键词结果冒充向量成功。

所有业务写操作除logout外带UUID格式Idempotency-Key；CAS写另带expected_lock_version，审核同时比对expected_head_id／version，不能以Idempotency-Key替代版本检查。幂等范围是组织＋成员＋operationId＋key，摘要覆盖明确目标、全部请求字段、NULL和版本，采用字段字典v1。服务端不接受客户端摘要。相同key及摘要返回同一资源／任务ID，不创建新版本、不再次收费；响应request_id可变，安全Task状态按当前权限更新。相同key不同摘要409 IDEMPOTENCY_CONFLICT；成功重放在已鉴权后优先返回原结果，不因第一次写入已推进lock_version而错误拒绝。不同key的主动重复交接按import_key／版本复用未开始或运行中任务，同时追加新的Submission／初评；不是同一请求重放。

S04已有Task／Submission等业务幂等键，不足以承担所有HTTP创建的响应回执；S05.2已通过0005_auth增加持久幂等回执及唯一范围约束，治理服务已使用，S05.4及后续业务写操作继续接入，与业务及审计同事务提交，记录稳定资源ID和输入摘要。不能用进程内字典／浏览器存储或审计扫描代替，也不在S05.1伪装已有回执服务。结果确认中断沿同key恢复；400/401/403/404/422和事务回滚不占用成功回执，正在提交的同key竞争由数据库唯一键／锁序解决，不并发执行两次。幂等记录随业务审计保留，不提前清理导致旧重放再次执行。

| HTTP | 代表code | 行为 |
| --- | --- | --- |
| 401／403／404 | AUTH_REQUIRED、AUTH_INVALID／CSRF_INVALID、ACCESS_DENIED／NOT_FOUND | 先会话及授权；不可见目标不泄露存在性 |
| 409 | VERSION_CONFLICT、IDEMPOTENCY_CONFLICT、REVIEW_STALE、CURSOR_EXPIRED、IMMUTABLE_INPUT、STALE_RESULT | 整个事务回滚；重新读当前版本或开始新逻辑操作，不静默覆盖 |
| 409 | BUDGET_EXHAUSTED、EXTERNAL_RESULT_UNKNOWN、CANCEL_UNCONFIRMED、STANDARD_NOT_APPROVED、MODEL_NOT_CONFIGURED、DATE_WINDOW_MISMATCH、SOURCE_UNAVAILABLE、FILE_NOT_ACCEPTED | 明确补授权／配置／来源或核验外部效果，不自动加预算或重发 |
| 422 | VALIDATION_FAILED、INSUFFICIENT_MATERIAL、UNSUPPORTED_SOURCE、PROVENANCE_DEPTH_EXCEEDED | 安全字段路径提示，不回显输入；补资料或修正请求 |
| 413／422／502 | FILE_TOO_LARGE／INVALID_FILE、UNSAFE_URL／FETCH_FAILED | 文件大小、格式或外链校验失败，清理本次未提交字节，不输出路径／URL |
| 429／503／500 | RATE_LIMITED／SERVICE_NOT_READY／INTERNAL_ERROR | 限流或未就绪明确失败，500不返回堆栈；调用方不静默回退Demo |

202不是业务完成，201不是AI批准或预测可比性验证。GET可以按取消信号读取，写操作不配置通用自动重试；只有明确同key恢复且有剩余权限／预算的情况才重放，外部结果未知先核验。Task失败的safe_error_code是安全类别，不透传供应商原文或私密输出。
