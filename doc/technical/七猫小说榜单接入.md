# 七猫小说榜单接入

版本：v1.0｜2026-10-31。适用AI漫剧情报流小说平台；不修改番茄／起点原有连接器。

## 一、方法与边界

与[番茄接入](小说榜单接入.md)同为普通公开HTTPS采集、来源证据与不可变快照入库；七猫采用HTMLParser解析官方SSR正文，不调用番茄接口、不执行`window.__NUXT__`脚本。沿用Qbook的独立平台适配思路及现有小说任务，使用Python httpx，无登录Cookie／人工浏览器／付费API／模型调用。

固定主机`www.qimao.com`，路径`/paihang/{boy|girl}/{hot|new|over|collect|update}/date/`。分别为男女频的大热、新书、完结、收藏、更新榜，共10榜；只解析首屏，每榜最多20条，不翻页补量、不采集章节正文。男／女、大热榜等导航必须与请求匹配，分页活动项必须为1，拒绝错榜、重复ID、非连续名次及外站作品链接。公开URL可在[男频大热](https://www.qimao.com/paihang/boy/hot/date/)与[女频大热](https://www.qimao.com/paihang/girl/hot/date/)核验。

串行至少10秒间隔，20秒超时、3MiB响应上限、TLS验证、不跟随重定向、单任务单请求单次尝试；403／429停止本批，不自动重试。其他失败保留HTTP状态与原文，只展示成功快照，不当空榜。完成后暂停来源；默认CLI不访问网络，显式`--execute`才运行，`--resume`只处理同日尚未记账部分，数据库同日来源任务仍幂等复用，成功请求不重跑。

## 二、字段与排序

`li.rank-list-item`提供每条作品；`a.s-book-title`取书名与`/shuku/{id}/`，`s-book-info`的作者链接取作者、分类链接取首级／二级题材，`s-book-intro`取简介，`rank-number`取原始名次。男女频来自页面真实频道，作品独立性别字段仍为空、卡片标明来源榜单。题材筛选取本批作品真实首级分类（例如都市、玄幻奇幻），卡片严格使用相同名称；原二级分类在`category_path`留证，不套用其他平台目录。选男女频／榜型时题材依实际已采样目录禁用，不宣称获取了七猫所有题材子榜。

热度只从明确带“热度”的`rank-change-num`提取`rank-num`＋`rank-unit`，如118.7万→1187000，保留`heat_display=118.7万`及`heat_value=1187000`；数字按十进制精确换算，不用字符串排序。相同CSS类也用于“上升1名”，只有名次变化时不能当热度。

七猫并非全部榜都按热度：大热榜官方说明“基于昨日书籍热度排行”；[收藏榜](https://www.qimao.com/paihang/boy/collect/date/)按收藏总数，[更新榜](https://www.qimao.com/paihang/boy/update/date/)按近30天更新总字数。页面指标列统一按用户要求名为“热度值”，未公开热度的榜单保留null并显示“-”，不能填收藏数或字数。在读人数始终null。各子榜保留官网原顺序；“全部”按来源／名次稳定合并去重，不伪造官方跨榜排名或补造未公开热度。

## 三、工程、存储与检查

- 连接器`backend/app/connectors/qimao.py`、任务`backend/app/collection/qimao.py`；复用`sources → collection_jobs/calls → raw_assets → content_observations → intelligence_snapshots/entries`，`source_tags`中的`novel-v1`保存热度、题材、标题、榜单及原名次。原HTML与SHA冻结，不将接口合成数据当网页证据。
- `0028_qimao`仅新增platforms字典，不新增表列或权限；回退时若有已引用来源／作品，外键拒绝删平台，必须保留证据。API允许qimao，并增加可空heat_value／heat_display；旧平台字段与缺失语义兼容。
- 小说下拉新增“七猫中文网”，默认仍番茄；初始／切平台三层全部，男女频切换重置题材。卡片、简介研判抽屉显示热度值；日历和顶部小说总数包含授权七猫快照，视频总数不混入小说。手动“重新采集”只对已配置七猫10来源执行；默认没有定时采集。
- 命令：`backend/.venv/bin/python scripts/collect_qimao.py`预览；`--execute`首次采集；`--execute --resume`中断续采；跨日明确刷新已有来源加`--refresh-existing`。本地回执`data/qimao/batch-YYYY-MM-DD.json`与原包仅私有保存，不提交书籍原文。
- 当前真实数量、测试、页面截图及问题见[实施与验收](../plans/2026-10-31-七猫小说榜单接入.md)。
