# 登录、权限与审计

版本：v0.2｜日期：2026-10-17｜S05.2。需求依据：[权限状态分册](数据字典-权限与状态.md)、[接口契约](接口契约.md)。本公共服务已实现；业务路由仍按S06／S07接入，文件流属于S05.3。无新增登录页面。S06.3按用户最新决定提供本地单人免手动登录，显式开启时自动创建专用本地工作区／南哥和E+O授权；关闭时不自动开户，下文受控账号流程保持。见[当前入口与限制](情报快照与本地工作区.md)。

## 一、运行与受控开户

先`pnpm db:upgrade`，确认APPLICATION_DATABASE_URL为受限应用角色。`pnpm accounts bootstrap --org-name '组织名称' --login '登录名'`在专用本地库建立新组织、首个管理员及R／E／V／A／O／M六份权限包，密码由getpass输入两次，15～1024字符；只输出组织／成员UUID。bootstrap每次是新组织，不用于重复初始化既有组织。仅初始管理员获M的org授权，M只有member.manage／role.manage／grant.manage／audit.read，没有内容、审核或模型配置特权。该命令是具备本地私密配置访问权的操作者入口，无HTTP注册接口。

后续命令均加`--org <组织UUID> --login <管理者登录名>`并交互验证管理者密码：

- `pnpm accounts roles ...`／`members ...`查询本组织治理目录（最多100项），成员返回不含password_hash；角色ID用于授权。
- `pnpm accounts member-add ... --new-login <新登录名> --name <显示名>`另行输入新成员密码；`member-disable ... --target <成员UUID> --expected-version <当前lock_version>`停用成员。
- `pnpm accounts grant ... --target <成员UUID> --role <角色UUID> --scope business --scope-id motion_comic`授予业务范围；org不填scope-id，work／file等填真实UUID。`revoke ... --target <GrantUUID>`撤权。
- `pnpm accounts role-set ... --target <角色UUID> --action content.read --action evidence.read`显式替换动作组合；`audit ...`读取最近100条本组织审计。写命令可传`--key <UUID>`恢复同一次操作；自动生成或显式传入的key在治理写入前向stderr输出并flush，结果再附同一key；提交结果丢失时使用该key恢复。

治理始终验证当前会话、精确动作和有效范围；org治理可授组织／业务／明确对象，business治理只能授同business范围，单对象治理只授同类同对象。成员／角色／模型配置／审计动作只接受org范围Grant。CLI本身使用受限应用连接；只有迁移／创建数据库角色使用owner。

## 二、会话与请求

运行接口为`POST／GET／DELETE /api/v1/session`，请求响应遵循生成OpenAPI。登录提交org_id＋login_name＋password，须有允许的精确Origin；开发默认127.0.0.1:5173与localhost:5173，通过ALLOWED_ORIGINS的JSON数组配置。无代理Header推导白名单。未开启SECURE_COOKIES时仅localhost／127.0.0.1 API Host可访问；HTTPS部署必须开启Secure并核验反向代理配置，正式部署尚未验收。

会话为256位随机不透明token，数据库只存SHA256摘要；cookie cip_session为HttpOnly、SameSite=Lax、/api/v1路径、8小时绝对有效期，生产Secure。CSRF由会话token派生，GET／登录响应可取得；写操作先验证会话再核对X-CSRF-Token。退出撤销持久会话，同一尚未过期凭据的重复退出幂等成功，不重复审计；无cookie、到期、停用或密码改变均401。密码采用随机16字节salt的scrypt（N=2^17、r=8、p=1、32字节输出），实现参数固定；未知账号与无效hash仍执行同成本KDF，登录错误统一AUTH_INVALID。

登录每10分钟限制同组织／登录名5次、同直接客户端地址30次，成功失败均计数；计数独立提交，不随失败回滚，忽略X-Forwarded-For。账号／客户端bucket均为摘要，不存原始密码或客户端请求体。HTTP成功／拒绝／校验错误使用脱敏信封、X-Request-ID及no-store；登录／退出审计关联HTTP request_id，不回显SQL或驱动参数。健康检查保持原liveness语义。

算法依据：[OWASP Password Storage](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html)、[Python hashlib.scrypt](https://docs.python.org/3/library/hashlib.html)。当前未接入外部身份提供商，登录密码／会话令牌不得进入前端localStorage或审计详情。

## 三、权限、查询与事务

`app/security/authorization.py`只从持久关系构建范围，组织／成员／Grant／role_actions实时重读，无权限缓存。当前公共读取支持Source、Work、Unit、Artifact／Version、InputSet、Report、Evaluation、Prediction、RawAsset、EvidenceRef、Knowledge／Revision、Standard／Revision、File和Task安全状态；未列对象默认拒绝，随业务阶段补齐并测试，不靠通用FK猜测放行。Task返回只含ID、kind、state、created_at、lock_version，Task Grant不开放输入或输出正文。

读取本体和每份输入分别授权，沿RawAsset处理父级、Artifact来源／血缘检查，最大32层，循环拒绝；报告／评价／预测检查完整InputSet，知识检查精确Revision业务标签及证据／来源报告。撤回与access_revoked使历史派生正文同步不可读，expired仅是警告。正式Knowledge读取投影为发布Revision标题及ID，候选标题／指针不外泄，未发布知识不会进入正式read／list；候选须显式candidate()或list(candidate=True)，知识修改权限检查须candidate=True，所有动作均绑定所选Revision业务范围。关键词筛选不以候选标题命中正式条目。后续正式知识全文／向量／标签检索由S07补齐。

公共列表先授权完整候选集，再分页；search复用同一检查，不输出不可读对象或泄漏计数。首期小数据量逐项检查，尚无cursor或权限缓存，S06／S07优化须保持相同行为。直接File读取须file／org的file.read，父路径须先读父对象，再确认file_id／cover_file_id实际关联及对应范围file.read，且文件accepted；本阶段只完成授权门，不读写文件字节、不签长期下载URL。不可见与不存在均NOT_FOUND；已可见但缺操作动作ACCESS_DENIED。

所有检查和写入共用S04组织事务互斥锁；网络不进入锁内，登录KDF先在锁外计算并在锁内重验凭据。撤权／角色动作／文件状态／发布指针／Revision业务变化同事务推进authz_version；到期直接比较数据库clock_timestamp，不能仅靠版本失效。受控写操作授权在幂等重放之前，回执、业务和审计同事务；相同key不同摘要拒绝，失败回滚不占成功回执。新增成员密码请求摘要先用scrypt绑定组织与key，防止回执形成快速密码猜测入口；不存请求正文。

## 四、增量数据字典与恢复

新增迁移0005_auth依赖0004_b1，旧SQL摘要保持不变。B1历史分组仍17／18／35，新服务表单列，共73表：

| 表 | 字段与约束 | 生命周期 |
| --- | --- | --- |
| auth_sessions | id UUID主键，org_id／member_id同租户FK，token_hash CHAR64唯一，credential_hash CHAR64，created_at／expires_at非空timestamptz且后者更晚，revoked_at可空 | 身份／摘要／时间不可改；只允许首次设置revoked_at，禁止物理删除。credential_hash绑定成员当前密码hash，修改密码即时失效 |
| auth_rate_limits | bucket CHAR64主键，window_start timestamptz非空，attempts integer>0 | 独立原子UPSERT；窗口过期在下一次请求重置。当前不自动删除bucket，维护清理后续落运行治理 |
| http_receipts | org_id＋member_id＋operation＋key UUID复合主键；同租户成员FK；input_sha256 CHAR64、response JSONB对象、created_at timestamptz | 永久追加，不允许UPDATE／DELETE；组织锁串行化同key竞争，只保存服务生成的稳定资源ID |

应用角色对session仅INSERT／SELECT及UPDATE revoked_at；回执仅INSERT／SELECT，无UPDATE权限，数据库另有不可变触发器。auth_rate_limits允许计数更新；审计沿S04不可变表追加。file_objects、knowledge_items发布指针、knowledge_businesses新增世代触发器。

`pnpm db:test`创建随机隔离库，空库升级、重复升级、降至base重建及合法／非法存量验证后运行所有数据库用例，最终删除仅本次创建的库；S05.2证据单列，不覆盖S04。0005 downgrade会删除新增会话／回执和限流历史，仅适用于隔离验收；运行库已有登录和治理历史后不可把降级当正常恢复，应先停止流量并备份，采用前向修复。文件存储、worker及前端联通分别留S05.3～S05.5。
