本文记录当前 Demo 已呈现的页面构成、视觉规则和交互行为，不将历史提案、后台规划或未接入能力写成已实现功能。核对以源码中实际使用的组件、渲染逻辑及 CSS 层叠结果为依据；2026-10-20列表简介灰色调整已进行三类型、双主题实屏校验。

2026-10-20用户确认：情报流视频、博主、小说三类榜单的剧情／内容简介统一使用辅助文字色var(--muted)，浅色#616670、深色#b0b4bd；标题、指标及字体尺寸／行数／布局维持。白色卡片对比度5.76:1、深色卡片8.02:1（最终实测值见[样式证据](technical/verification/2026-10-20/feed-summary-gray-ui.json)），悬浮全文仍按现有弹层阅读样式。Demo基线36e1074a200a，见[实施记录](plans/2026-10-20-起点女生自动采集验证.md)。

**强制执行（2026-10-15用户确认）：前端必须严格按[当前Demo](prototypes/index.html)开发，直达示例为[研判室／内容研判](prototypes/index.html#2/0)。** 本文用于提取和说明Demo设计，不授予重新设计权限；视觉、布局与交互出现描述差异时以经用户确认的Demo为准。不得以历史参考图、旧规范或个人偏好更换方案；可见差异须先经用户确认。开发完成需在同主题、同视口实际操作并逐项对照。

## 一、页面壳与导航

### 1、一级入口与二级工作区

桌面采用固定宽度侧栏与右侧内容区。侧栏按“情报局、研判室、藏经阁、控制台”排列，保持四个一级入口，不将业务线或知识分类另建为一级模块。

| 一级入口 | 二级工作区 | 当前主要呈现方式 |
| --- | --- | --- |
| 情报局 | 情报流、选题卡、待生产 | 紧凑情报长卡片、选题网格、右侧详情抽屉 |
| 研判室 | 内容研判、发布复盘、规律验证 | 作品长卡片与完整作品页；复盘、验证采用表格及详情 |
| 藏经阁 | 知识浏览、入库处理、审核队列、回收站 | 分类与知识卡片；资料处理表格、审核详情 |
| 控制台 | 采集配置、处理配置、评价标准、权限管理、运行状态、模型配置 | 配置卡片、表格及配置／任务详情 |

侧栏桌面宽204px，1150px以下收窄至180px；760px以下改为顶部横向导航。选中项使用独立导航颜色、700字重、12px圆角底色及左侧4px竖线。图标未选中为线框，选中为对应的实心 SVG，颜色继承导航文字色。

内容区最大宽1440px，桌面内距28px，底部预留96px；窄屏逐步缩小内距。四个模块不展示二级导航下的重复页面引导说明，保留不占布局空间的读屏标题。有操作时才渲染操作行，无操作不保留空行。

### 2、顶栏、业务线与面包屑

顶栏为实色背景，`position: sticky; top: 0; z-index: 12`，最小高度58px；窄屏允许换行撑高。左侧显示面包屑，右侧显示全局业务线单选和主题切换。

业务线为“AI漫剧｜故事短片｜电商短视频”，初次默认故事短片，后续读取浏览器已保存的选择。左侧“业务线”是12px纯文字，不带边框和底色。三个按钮等宽，桌面组宽264px、间距6px，即每个84px，最小高度29px；选中使用主题文字、浅选中底及品牌色边框。业务范围跨模块沿用，页面筛选不替代全局业务选择。

二级导航使用文字下划线 Tab：无胶囊背景和边框，桌面字号14px、最小高度33px；选中为600字重主题文字及3px底线。窄屏字号12px，保留横向溢出浏览能力。

作品详情的面包屑为“研判室 › 内容研判 › 作品名”。前两级是原生 Hash 链接，分别返回模块默认入口和作品列表；当前模块默认入口也是内容研判。作品名标记当前页，超长省略，并保留完整标题提示。返回列表或切换工作区后移除作品层级。

页脚只保留右侧版本及本地演示说明。侧栏、顶栏不再显示原型说明入口。

### 3、操作行的实际对齐

“新增选题／AI再来5个”、待生产页“新增选题”、内容研判“新建研判”、知识浏览“人工新增”均左对齐，间距10px，可自然折行。其余仍使用默认操作行的页面，例如入库处理“提交资料”、采集配置“新增来源”，当前保持右对齐。不要将“全部新增按钮都在右侧”或“全部都在左侧”写成统一规则。

普通主按钮为橙红实色配白字。研判按钮及可查看的作品报告按钮使用135度柔和红色渐变 `#bb4947 → #aa3c50`，悬停为 `#b44243 → #983347`；“加入待生产”使用105度渐变 `#c24d24 → #9e2855`，悬停为 `#b34320 → #8b214b`。

**现有主题例外：**深色模式下，`.cards-grid:not(.topic-grid) > .card`使用局部浅色变量，仍是白色卡面配深色文字；知识卡片属于此范围。选题卡及待生产网格随全局主题变化。本文如实保留这一现状，不将其描述为全部网格已完成深色适配。

### 2、字体、密度与形状

字体采用系统后备链：SF／苹方／冬青黑体／微软雅黑／Noto Sans CJK SC／思源黑体／Arial，不下载字体。正文基准15px、行高1.65，卡片摘要和分析正文常用14px，辅助信息11—12px。

| 组件 | 当前关键尺寸与排版 |
| --- | --- |
| 通用网格卡片 | 16px圆角，桌面内距22px；标题18px、摘要14px |
| 情报长卡片 | 14px圆角、最小高度80px；标题16px／650，剧情14px／400 |
| 作品长卡片 | 14px圆角；名称15px／650，覆盖／进度13px，元信息11px |
| 普通按钮 | 10px圆角；普通主按钮600字重，筛选和标签保留各自圆角 |
| 搜索框 | 34px高、11px圆角，输入文字13px |
| 情报流三项指标（视频／博主／小说） | 最小高度78px，数字30px／650；名称、数字整组横纵居中 |
| 研判弹窗互动指标 | 名称与数字整组横纵居中，数字18px／650 |
| 作品详情概况 | 六个概况块，数字与文案横纵居中，普通数字23px，报告版本18px |
| 评分条 | 6px高，主题色填充与中性轨道，未知不当作0分 |

情报流指标数字在1150px／760px／390px以下分别为27px／25px／23px，760px以下指标块最小高度68px。卡片以边框和表面分层，普通表面无阴影；弹窗、下拉菜单及全文浮框使用局部阴影。

### 3、弹窗、表单和浮层

普通弹窗最大宽560px，且不超过视口减32px，最大高度90dvh；右侧抽屉最大宽610px、全视口高，窄屏可占满宽度。弹窗圆角18px，抽屉仅左侧保留圆角；头部和底部操作区在滚动区域中保持可见，底部按钮可折行。

表单显示明确标签、必填校验及错误位置。情报研判的并排字段使用等宽布局、16px间距、180px最小宽度，控件44px高；说明文字放控件下方，不挤歪相邻字段。条件隐藏字段同时停用，避免隐藏输入参与提交校验。

全文浮框只在情报标题／剧情实际溢出时出现，支持悬停和键盘聚焦。最大宽480px、高360px，自动换行并可滚动，距视口边缘至少12px；底部不足时向上放置。移入浮框可继续阅读，离开延迟150ms关闭，Esc、页面切换或相关滚动可关闭。

## 三、四模块的当前页面构成

### 1、情报局

**情报流。**二级导航右侧仅此工作区有日期选择，控件33px高，无“最新”按钮。顶部仅视频、博主、小说三项数量，三个等宽卡片，文字与数字横纵居中；三类来源都展示同一概览，不显示评论或点赞统计，也不随局部筛选变化。信息源为视频／博主／小说三个互斥按钮，前两者承接原榜单／达人视图；对应筛选和搜索按类型呈现；宽屏主列表与216px洞察侧栏并排，洞察可收起。

情报条目左侧为序号、标题、来源／博主／题材和单行剧情，右侧为赞、转、评、藏。反馈入口和最多两个中性情绪标签位于互动区下方左侧，“研判”在同一底行右侧。剧情和互动数字为常规字重，不用强调色突出整段剧情；列表不重复业务标签、更新时间及“演示”尾标。关键反馈放在研判初评或详情中阅读。

小说列表与视频列表共用feed-single布局容器，长条卡片桌面为左文右指标。书名16px／650字重，简介14px、行高22px、最多两行，标题用正文色、简介用辅助灰色；平台／榜单、作者与题材另行展示。右侧独立显示居中的在读人数（数值18px／600）及右对齐研判按钮，不占用简介下方整行；850px以下沿用视频卡片的堆叠规则。隐藏视频四项互动、反馈提示及视频洞察，保留共用三项概览，提供独立小说平台下拉（全部平台／番茄小说／起点中文网）和书名／作者／简介搜索。控制行下方以边框容器放三行筛选标签：榜单类型、男女频分类、题材分类；标签名称列76px；按钮高22px、字号11px、内距1px 8px，明显小于上方高34px／字号12px的来源按钮。行间距4px、容器内距8px 12px、下边距14px，名称及提示也用11px文字；窄屏同样保持22px标签高，不受通用按钮40px最小高度覆盖。各行当前仅禁用的全部标签及待接入提示，具体值不预设，窄屏自然折行。研判抽屉同步只显示在读人数；小说采集未接时，React真实页为明确空态。

观众反馈使用右侧抽屉，呈现样本范围、情绪分布、归纳及原文证据；文字和条数／比例同时存在，相关证据可定位。宽屏情绪分布为双列，窄屏单列。

**提交研判。**抽屉包含原内容、互动指标、观众反馈、人工S／A／B／C评级、业务／题材及学习点。业务类型为AI漫剧时，业务类型与作品名称组合框等宽并排，下一行是总集数和当前第几集。作品名支持匹配既有作品或输入新名称，匹配列表显示名称和编号，支持方向键、Enter和Esc；其他业务隐藏漫剧字段。总集数允许留空，集号和材料归属不从相似标题强行猜测。

**选题卡与待生产。**桌面每行3张，1100px以下2张、760px以下1张；选题每页9张。点击卡片、标题、评分及“编辑”打开同一详情抽屉。漫剧评分在卡片左上角原业务标签位置，只显示数值／50或待评估状态，底栏保留编辑、加入待生产等操作。“编辑”“加入待生产”最小高度29px、字号13px；“交接选题”最小高度34px、字号14px。

详情依次为基础字段、Logline、角色设定、全局节奏、承重力评估和记录。角色设定是一个全宽自由编辑框，最小高度180px，不拆成主角／反派两个框；旧角色内容合并回填，复制／导出读取同一份内容。

承重力为内容、市场各五维，每维5分，共50分；总分与“承重力评估”标题同排靠右。十维以标题、解释小字、比例条、分数紧凑呈现；桌面列宽为98px／剩余空间／82px／42px。比例条独立占列、左侧起点一致，不压在解释文字上；460px以下调整为标题84px，条形移至解释下方。页面不展示旧总说明和逐维分析长段落，历史评分数据仍保留。

“保存并重新评分”在内容未变时灰色禁用，有实质改动才启用，改回原内容重新禁用并恢复原评分。保存新版本后显示待评分；Demo只保存请求，不伪造新的AI评分。

**闪念胶囊与头脑风暴。**保留右下蓝紫入口，数量统计独立闪念。闪念弹窗桌面左右两栏：左侧自动保存的自由文本和“新记录”，右侧历史小胶囊，点击回看。头脑风暴入口紧跟“新增选题”；弹窗左侧为可拖动／点击的历史胶囊，右侧为组合区、可选方向和单个生成结果。结果包含可编辑标题、Logline、角色设定与全局节奏，保存后进入统一详情并展示来源快照。桌面弹窗分别最大960／1040px，760px以下改为上下布局；胶囊区域内部滚动，长文本换行。生成结果显式标注“演示 · 未调用AI”，不编造评分。

### 2、研判室

**内容研判列表。**作品为一条长卡片，按身份、资料覆盖、处理进度、最新报告及操作组织。卡片显示封面、作品名／编号、题材和博主ID；58×58px缩略图优先封面，其次视频帧，图片和视频都不可用才回退首字。搜索支持作品名、编号和博主信息，与题材筛选结合；不显示适用环节筛选。

状态筛选为“全部、处理中、需处理、待复核、已有报告”。各组按作品去重，但可交叉命中；报告与单集运行／失败状态并列，已有阶段报告不因补集处理中而隐藏。旧聚合数据不能提供完整逐集记录时，明确标识含历史汇总。

点击整卡或名称进入完整作品详情页，Enter／空格也可进入；“查看报告”直接打开该作品的作品分析区。返回列表保留局部筛选，顶部业务切换退出原作品。

**作品详情。**顶部含66×76px缩略图、作品身份、操作与六个概况块：总集数、已收集、已分析、最新报告、总观看量、互动量。观看量和互动量未获取时视觉留空，真实0正常显示；快照提供平台、范围和时间。下方是“作品分析／分集分析／资料与记录”，漫剧默认分集分析，其他业务使用“内容分析”文案，不强制第1集。

分集区桌面为250px导航加弹性正文，1000px以下导航收窄至210px，820px以下上下排列。导航每集一行，最小高度40px，34px序号列加可伸缩标题列；标题超长省略。已有资料用正文色，缺资料用辅助色，选中项有底色与当前项语义。**当前没有分集搜索框和状态下拉菜单。**

总集数已知时列出全部集号，缺集可选并显示空态及“补充该集资料”；未标集资料单列，标题未知不补造。超过100集使用分段按钮，链接可恢复选集及所在分段。导航独立滚动，窄屏列表限高240px。右侧依次阅读原始内容、人工初评、反馈、拆解、证据和知识，可切换材料／历史执行记录。

**作品分析文档。**所有分析在一个连续格式化文章容器中呈现，不为各部分另套文本框。十部分依次为：0作品优缺点、1故事大纲、2情绪与母题、3人物设计、4世界观与长线悬念、5情节与冲突、6节奏结构、7终局设计、8剧情发展高潮曲线、9观众评论反馈总结。每部分分别显示事实分析和改写建议，已有证据可跳到对应单集／材料。

文章二级标题16px，事实／建议小标题13px，正文14px、行高1.85。高潮曲线内嵌，采用主题线条与中性网格，只绘制本报告范围内已有点位；暂无报告也保留十部分框架，明确待分析，不补造曲线、结局或评论。人工初评、评价／预测、候选知识审核放在同一文章的附录或记录区域。

报告版本保留独立覆盖范围，补集不自动扩大旧报告。作品级资料、提交批次／执行记录和报告历史位于“资料与记录”。补资料区分作品级和单集级，同集新版本不重复计数；失败重试只记录新的本地待处理请求。单集与作品候选知识都可送审，不能直接显示为正式知识。

**发布复盘与规律验证。**当前仍为表格列表配详情：前者展示发布、内容版本、窗口和实绩来源，后者展示候选规律、新旧标准、样本及验证状态。它们尚未改为作品详情同样的单篇文章布局，不将后者样式泛化为全模块规则。

### 3、藏经阁

知识浏览的“人工新增”在左侧。其下为“全部＋题材库、金句库、爽点库、翻车点、DNA经典案例”切换，再下为搜索和知识网格；**当前不展示适用环节筛选，旧隐藏环节状态也不参与过滤。**分类按钮最小高度36px、13px文字，带当前业务正式知识计数，窄屏自然折行。

分类与关键词共同筛选，旧未分类条目留在“全部”中，不按标题猜归属。卡片保留分类、原类型、环节、业务、编号和版本等元信息。人工新增／修订需选择知识分类，从具体分类进入新增时自动带入，提交后仍进入待AI审核；候选与正式知识分开显示。

入库处理是资料表格，审核队列和回收站沿用卡片及详情；分类未另建五套入库或审核工作区。详情保留来源、适用范围、审核和版本信息，删除仍展示进入回收站的确认流程。当前原型不执行30天自动永久清理。

### 4、控制台

采集配置为榜单类型／监测达人配置卡片加来源表格；处理配置、评价标准、权限管理和运行状态以表格及详情为主。配置项、审核状态和任务结果使用共享表面、边框、标签、按钮及错误提示，不引入另一套视觉主题。

模型配置为独立Tab（`#3/5`），按“单文本、多模态”两类分别维护多个模型源，各有来源数量和新增入口；当前业务的各处理环节独立选择对应类型的来源。连接表格与新增／编辑抽屉沿用现有控制台组件；分配区桌面三列，1100px以下两列，600px以下单列。模型类型限制可选来源，密钥仅填写服务端引用；保存为未验证的本地草稿。Demo监测达人新增表单在名称下方增加个人主页链接，名单可打开已保存主页。已接真实采集的React表单仍沿用原稳定UID输入，本轮主页字段不宣称已接服务端。

权限矩阵及部分配置为只读设计样例；任务重试和来源开关的本地演示不代表真实平台、模型、授权或任务服务已接通。

## 四、交互、状态与响应式核对

### 1、交互与数据表达

按钮、链接、输入和选择器保留可见键盘焦点；整卡入口支持键盘操作，弹窗可关闭，组合框支持基础键盘选择。列表选中、资料缺失、审核与处理状态通过文字或语义补充，不只依赖颜色。

缺失信息不默认转换为0、零分或成功结果。作品表现优先读取独立快照中的互动总量；仅当赞／评／转／藏分项齐全时才可求和，不把多个累计快照相加。人工初评与AI判断分开，后续提交不改写原证据快照。

选题实质修改、材料新版本和重试保留历史记录。未保存修改有离开确认；保存失败须呈现反馈。Demo的浏览器本地保存不是服务端持久化，不作为正式权限或并发控制。

现有页面状态预览包括正常、加载、空数据、失败、无权限、证据不足和评价过期，使用空态、骨架、说明及恢复入口。业务暂无数据时展示当前范围空态，不用其他业务的数据填补。
