# 内容研判作品详情 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** 按已获用户授权的页面构成讨论，将作品抽屉调整为完整作品详情，区分作品分析、分集分析与资料记录。

**Architecture:** 沿用独立HTML原型和浏览器本地数据，不新增框架。作品由稳定ID关联任务，已知集数按集号分组，未标集资料单列；报告保存独立覆盖范围。Hash承载作品、页签和选集，返回列表保留局部筛选。

**Tech Stack:** HTML / CSS / JavaScript；Node内置fs、vm、assert验证。

**Spec:** [研判室模块](../modules/研判室.md)第四章；2026-10-14对话已确认的作品卡片 → 作品详情 → 单集分析方案。

## Global Constraints

- 本轮仅调整Demo；真实采集、解析、分析、报告生成与视频播放素材未接入，不模拟成功。
- 卡片仍为长条卡片；业务空间隔离；故事短片及电商不强制第1集。
- 人工初评、历史版本、原证据及用户已有数据保留；候选知识须双审。
- 不创建Git或依赖；沿用浅深主题，窄屏可用、键盘焦点可见。
- 本地浏览器控制曾被安全检查拒绝，本轮不绕过限制；隔离验证不能代替实屏验收。

## Review Focus

- 同集多版本／重试不能重复计数或把旧分析当新版成功。
- 1、3、8集及未知集号不能被重新连续编号。
- 新任务运行／失败时仍可查看旧报告，报告不扩大覆盖范围。
- 直达链接刷新／后退及切换业务不能串作品。
- 文本、媒体URL和证据跳转须安全处理，未知信息不伪造。

## Execution Ledger

- Ruling: 旧资料没有可靠集号时归“未标集资料” — 避免用标题或列表顺序猜集号 — 用户需后续确认归属。
- Ruling: 独立新增演示作品承载完整多集样例 — 保留旧样例及用户修改 — 列表多一条演示作品。
- Ruling: 不新建真实任务服务 — 当前独立Demo边界 — 重试及新增资料只记录本地待处理任务。

- Task 1/2 验证：新增作品详情检查先失败于整卡入口／补资料返回，再通过；筛选后的版本操作发现绑定旧单集的问题，补回归后修复。
- Ruling: 继承旧候选的researchId关联 — 保证历史知识仍可在单集阅读 — 不要求批量改写旧知识对象。
- Task 3 验证：两个Node行为检查及独立脚本语法检查，文档索引和新增链接核对；浏览器安全限制下不开展实屏验收。
- Review: 单集版本与重试计数、报告覆盖范围、材料归属、候选双审和业务隔离已逐项自检；真实模型及自动报告流程未接入。
